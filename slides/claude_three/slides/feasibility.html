Each hexagon is one layer of the stack, and its shape shows how ready it is. Solid means ready today: the experience already runs as our prototype; the AI layer uses enterprise model APIs, Claude or GPT behind one PNC gateway, with no model training; and the formulas are plain code already in the prototype. Outlined means a standard build: encrypted member vaults, a consent ledger and an audit log, all patterns PNC already runs. Dashed means validate first: using business-account activity as a sale signal needs data access and a compliance review. That is why the pilot is staged over ninety days. First we connect the gateway and consent ledger with five advisors. Then we back-test the signal on past client exits. Then we run with ten families and aim for seventy percent check-in completion. Phase one does not depend on the signal: it can start on referrals the owner authorizes.
