Read the stack from the top. The experience already runs as our prototype, on phones and desktops. The AI layer uses enterprise model APIs, Claude or GPT behind one PNC gateway, with no model training required. The formulas, the proceeds calculator, the gap score and the decision tree, are plain code and already work in the prototype. Data and consent is a standard build: encrypted member vaults, a consent ledger and an audit log, all patterns PNC already runs. Only one layer needs validation first: using business-account activity as a sale signal requires data access and a compliance review. That is why the pilot is staged. In the first thirty days we connect the gateway and consent ledger with five advisors. In days thirty-one to sixty we back-test the signal on past client exits. In the last thirty days we run with ten families and aim for seventy percent check-in completion. Phase one does not depend on the signal: it can start on referrals the owner authorizes.
